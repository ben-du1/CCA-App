# CCA App 📱
Welcome to the master repository for the Canyon Crest Academy mobile application. If you know someone interested in contributing, invite them to the [Discord](https://discord.gg/DGBm7KhQuE) & Meetings!

# Features
## Home
- Displays posts about school events in feed
- CCA TV & Bulletin Links
- Bell Schedule
## Map
- Icons denote Teachers
- Responsive Search
- Office Hours
- Room Numbers
- Classes Taught

# Get Started
1) The CCA App uses [expo](https://docs.expo.dev/), install it [here](https://docs.expo.dev/get-started/installation/)
2) Recommended: [Expo Go](https://expo.dev/go) is a utility app that allows you to test code across platforms
4) Run `npx expo start` to start the app

# How to Contribute

## Guidelines
- Should be familiar with TS/JS & React Native
- Work on your own branch
-  **Submit pull request & request review before merging**

## Developing For IOS
- Run on Expo Go using your personal IPhone
- Open on IOS Simulator (Requires XCode 🤢)
- If you have the Apple Developer Program (DM AN OFFICER IMMEDIATELY 🤑), you can download a development build directly onto your device 

## Developing For Android
- Run on Expo Go using your personal Android device
- Open on Android Developer Studio Simulator
